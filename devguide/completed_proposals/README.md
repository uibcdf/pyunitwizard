# Completed proposals

This directory preserves proposals whose implementation and verification are
complete. They remain as design and benchmark evidence, but they are no longer
part of the active backlog.

- `python_overhead_before_rusterization.md`: Python fast-path and import-cost
  work completed before considering a native core.
- `cheap_canonicity_predicate.md`: implemented as the public `has_unit()`
  predicate and integrated into unit validation.
- `docs_autosummary_artifact_policy.md`: generated autosummary trees are now
  ignored by git and removed by the docs build itself.
